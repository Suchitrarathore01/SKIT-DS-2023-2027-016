# ChainShield

ChainShield is a blockchain-backed system for detecting phishing and smishing (SMS 
phishing) in real time. Known threats are checked instantly against a blockchain 
registry; unknown messages are classified using machine learning, and confirmed 
threats get added to the registry so they are recognized instantly next time.

## Team and components

This is a 4-person team project. Each person owns one component:

| Component | Owner | Folder |
|---|---|---|
| ML detection (phishing/smishing classification) | [Name] | `src/`, `data/`, `models/` |
| Smart contract (blockchain threat registry) | [Name] | `contracts/` |
| Backend (connects ML model and contract, serves predictions) | [Name] | `backend/` |
| Frontend (Chrome extension and dashboard) | [Name] | `frontend/` |

## How it works

1. A message or URL comes in through the Chrome extension.
2. The backend checks the blockchain registry first. If it's already a known, 
   confirmed threat, it returns the verdict immediately (fast path).
3. If it's not known, the backend sends it to the ML model for classification 
   (slow path). If the model is confident it's a threat, it gets submitted to 
   the blockchain registry for community confirmation.
4. The dashboard shows stats: total scans, confirmed threats, model accuracy.

ML component

Dataset: data/raw/smish.csv (SMS smishing text) for the text classifier, plus a
URL-based dataset for the phishing-link side. Not committed to git.

Run order:

bash
python -m src.eda.run_eda
python -m src.data.clean
python -m src.data.split
python -m src.training.train_baseline
python -m src.evaluate.evaluate

DistilBERT fine-tuning (src/training/train_distilbert.py) needs a GPU and is run
on Kaggle. After training, the model is downloaded from Kaggle and placed in
models/model_v1/.

Smart contract component

Built with Solidity and Hardhat, deployed to a public testnet (Sepolia or Polygon
Amoy). See contracts/README.md for setup and deployment steps.

Backend component

FastAPI app that loads the trained model and connects to the deployed contract
using Web3.py. See backend/README.md for setup steps.

Frontend component

Chrome extension (Manifest V3) for real-time scanning, and a React dashboard for
viewing stats. See frontend/extension/README.md and frontend/dashboard/README.md.
