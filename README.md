# ChainShield

ChainShield is a blockchain-backed system for detecting phishing and smishing (SMS 
phishing) in real time. Known threats are checked instantly against a blockchain 
registry; unknown messages are classified using machine learning, and confirmed 
threats get added to the registry so they are recognized instantly next time.


## How it works

1. A message or URL comes in through the Chrome extension.
2. The backend checks the blockchain registry first. If it's already a known, 
   confirmed threat, it returns the verdict immediately (fast path).
3. If it's not known, the backend sends it to the ML model for classification 
   (slow path). If the model is confident it's a threat, it gets submitted to 
   the blockchain registry for community confirmation.
4. The dashboard shows stats: total scans, confirmed threats, model accuracy.
